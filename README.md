# TapyNote

Minimal sticky-note widget for Android (8.0+).

- Long-press home screen → **Widgets** → **TapyNote** → drag it out (or tap "Add note to home screen" in the app).
- Tap the note to edit; it saves automatically when you close the editor.
- Each widget holds its own note. Resizable.

## Build
`./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`.
Every push also builds the APK in GitHub Actions (download it from the run's Artifacts).
